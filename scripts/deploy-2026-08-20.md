

embutidas no bundle e um erro aqui só apareceria em produção, como tela branca.

## Se algo der errado

Voltar é trocar a versão e subir de novo:

```bash
export APP_VERSION=<versão anterior>
docker compose -f docker-compose.prod.yml up -d app
```

As migrations **não** voltam com isso. Se precisar reverter alguma, o cabeçalho
de cada `.sql` tem a reversão — exceto as duas citadas no passo 4, que não têm.
