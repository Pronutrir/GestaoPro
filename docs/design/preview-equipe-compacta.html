Para onde foi a descrição do nível. Ela se repetia em toda linha de quem tem o mesmo nível — três "cria, edita e move qualquer atividade" idênticos empilhados. Agora ela aparece dentro do dropdown, que é onde importa: quem está escolhendo lê as quatro opções com o que cada uma faz; quem só está conferindo lê o nome do nível, que basta.

O que mudou, em resumo
  • Três faixas viram uma: identidade à esquerda, permissão à direita
  • Cargos agrupados por pessoa — acabou o nome repetido
  • Avatar 24→20px, nome 14→13px, etiquetas menores
  • Descrição do nível migrou para dentro do dropdown
  • "Aguardando aceite" virou "Aguardando": o texto longo empurrava o nome para a reticência
  • Espaçamento entre linhas de 8px para 4px
Um detalhe técnico que quase quebrou. A descrição não pode entrar direto no <SelectItem>: o Radix clona o conteúdo do item selecionado dentro do gatilho, então as duas linhas estourariam a altura de 28px do campo fechado. O gatilho renderiza o nome à parte, e o item usa textValue para a busca por digitação continuar funcionando.
