Gestão Pro — o desenho aprovado

Dez telas, num arquivo só. Cada uma é HTML de verdade: os valores estão em style= inline de propósito, para serem lidos e copiados direto. Este arquivo é a referência para construir — não um esboço para se inspirar.

Copie os valores exatos. Cor, tamanho de fonte, peso, espaçamento, gap, raio de borda, largura de coluna, altura de controle. Não arredonde para múltiplos de 4 ou 8, não substitua por padrão de framework, não “melhore” o espaçamento. Se algum valor conflitar com o que já existe no sistema, pare e pergunte em vez de escolher sozinho.

Regras que não são negociáveis

  • número sempre à direita e com tabular-nums
  • vazio diz o que falta — sem responsável, sem data — nunca 0, traço mudo ou a definir
  • status é um ponto de 7px, nunca pastilha
  • GUT só ganha cor a partir de 60
  • sem zebra: o que separa é a faixa de grupo
  • campo sem permissão vira texto; botão sem permissão não aparece — nunca apagado
  • agrupador não é trabalho: só Atividade vira cartão no quadro
  • quatro cores no total na tela inteira, contando tudo
